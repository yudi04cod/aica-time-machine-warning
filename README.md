The funniest one-line warning label for a time machine, in 120 characters or fewer.

> WARNING: If you arrive before you departed, remain calm. You already panicked about this yesterday.

## How it works

`main.py` (Python standard library only) writes the warning label to `/output/entry.txt`. It validates the entry first — non-empty, a single line, at most 120 characters — then writes it.

```sh
python3 main.py
```
